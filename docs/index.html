What got measured

  1. general QA
  2. JSON extraction
  3. Darija / French / English translation sanity

Scorers include exact, regex, JSON Schema, contains, fuzzy similarity, and optional LLM-as-judge (with bias warning in the README).

How it works

  1. Write suites YAML / JSON / JSONL cases with expected + scoring method.
  2. Run models Mock, OpenAI, Groq, Ollama — any OpenAI-compatible API.
  3. Score honestly Deterministic scorers first; judge models optional.
  4. Compare Terminal table + HTML + JSON; diff two runs for regressions.

Quick start

py -3.12 -m pip install -e ".[dev]"
llm-eval run suites/ --models mock --out reports/mock-run --judge-model mock
