# llm-eval-harness

Tiny, honest framework to compare LLM models on **your own** prompt suites.

> Skeleton only — full docs and real mock-run metrics land after core + e2e land. See `PROGRESS.md`.

## Quick start (planned)

```bash
pip install -e ".[dev]"
llm-eval run suites/ --models mock --out reports/mock-run
```
